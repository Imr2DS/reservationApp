## 🔥 Featured Projects

### 🎯 [Reservation App](https://github.com/Imr2Ds/reservationApp)
A full-stack resource reservation management system built with microservices architecture.

**Tech Stack:**
- **Backend:** Spring Boot, Spring Cloud (Config, Gateway, Eureka), JWT Authentication
- **Frontend:** Angular 16, TypeScript, RxJS
- **Database:** MySQL 8
- **DevOps:** Docker, Docker Compose, Multi-stage builds
- **Architecture:** Microservices with API Gateway, Service Discovery, and Centralized Configuration

**Features:**
- ✅ User authentication and authorization (JWT)
- ✅ Resource management (CRUD operations)
- ✅ Reservation scheduling and management
- ✅ Role-based access control (USER/ADMIN)
- ✅ Fully containerized with Docker
- ✅ Service discovery with Eureka
- ✅ Centralized configuration management
- ✅ API Gateway for routing and load balancing

**Branches:**
- `main` - Standard deployment
- `docker-version` - Fully containerized with Docker Compose
