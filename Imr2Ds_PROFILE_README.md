## 📊 Featured Projects

### 🎯 [Reservation App](https://github.com/Imr2Ds/reservationApp)

A comprehensive full-stack resource reservation management system built with microservices architecture.

**🏗️ Architecture:**
- **Backend:** Spring Boot microservices (User Service, Resource Service, Reservation Service)
- **Frontend:** Angular 16 with TypeScript
- **Infrastructure:** Docker & Docker Compose
- **Service Discovery:** Netflix Eureka
- **API Gateway:** Spring Cloud Gateway
- **Configuration:** Spring Cloud Config Server
- **Security:** JWT Authentication & Spring Security

**✨ Key Features:**
- 🔐 JWT-based authentication and authorization
- 👥 User management with role-based access control (USER/ADMIN)
- 📦 Resource CRUD operations
- 📅 Reservation scheduling and management
- 🐳 Fully containerized with Docker
- 🔄 Service discovery and load balancing
- 📊 Centralized configuration management
- 🗄️ MySQL database persistence

**🛠️ Tech Stack:**
- Java 17, Spring Boot 3.2.x, Spring Cloud 2023.0.x
- Angular 16, TypeScript 5, RxJS
- MySQL 8, Spring Data JPA
- Docker, Docker Compose, Nginx
- Maven, npm

**📂 Project Structure:**
```
reservationApp/
├── reservation_system/    # Backend microservices
│   ├── config-server/    # Centralized configuration
│   ├── discovery-service/ # Eureka service registry
│   ├── api-gateway/      # API Gateway
│   ├── user_service/     # User management & auth
│   ├── ressource_service/ # Resource management
│   └── reservation_service/ # Reservation management
└── frontend/             # Angular application
```

**🚀 Quick Start:**
```bash
git clone https://github.com/Imr2Ds/reservationApp.git
cd reservationApp
git checkout docker-version
docker-compose up -d
```
